# Mad1_Project

Hospitals need efficient systems to manage patients, doctors, appointments, and treatments. 
Currently, many hospitals use manual registers or disconnected software, which makes it difficult to manage records, avoid scheduling conflicts, and track patient history.


# Frameworks to be used

- Flask for application back-end
- Jinja2 templating, HTML, CSS and Bootstraps for application front-end
- SQLite for database (No other database is permitted)
